Screens

  • Portfolio · all installed repos, sortable, parity at a glance
  • Repository · parity banner, tiles, four trend charts, change feed
  • Findings · open list with filters, a detail panel (location, excerpt, how to clear, history) and a resolved tab
  • Component · every metric for one component, mutation detail
  • States · sign-in, install, empty, gap, no access, stale

Capabilities

  • Branch picker, range picker (30d, 90d, 1y, all)
  • Hover tooltip with commit, date, ruleset
  • Gaps drawn as breaks, ruleset changes as markers
  • Deep link to a repo, branch and range
  • README badge via the Worker proxy (later)
  • Offline: lydite report emits one HTML file

Not in 1.0

  • Triage, assignment or dismissing findings (read-only)
  • Light theme and layouts below 1240px
  • Alerts and notifications
  • Any data stored by lydite
